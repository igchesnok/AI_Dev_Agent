# AI Dev Agent - Полноценный AI-помощник для разработки

Полностью функциональный AI-агент с интеграцией OpenRouter API для автономной работы с кодом.

## 🚀 Возможности

### Реальные возможности AI-агента:

1. **🔍 Анализ кода** - AI читает и понимает структуру проекта
2. **💡 Генерация решений** - Создаёт код на основе ваших задач
3. **🧪 Создание тестов** - Автоматически генерирует unit-тесты
4. **🐛 Исправление ошибок** - Находит и исправляет баги
5. **⚡ Оптимизация** - Предлагает улучшения производительности
6. **📊 Стриминг ответов** - Видите ответ AI в реальном времени

## 📦 Установка и запуск

### 1. Установите Node.js
Скачайте с https://nodejs.org (версия 18+)

### 2. Установите зависимости
```bash
npm install
```

### 3. Запустите проект
```bash
npm run dev
```

### 4. Откройте в браузере
Перейдите по адресу: http://localhost:5173

## 🔑 Настройка OpenRouter API

### Получите API ключ:
1. Зарегистрируйтесь на https://openrouter.ai
2. Перейдите в раздел Keys: https://openrouter.ai/keys
3. Создайте новый API ключ
4. Скопируйте ключ (начинается с `sk-or-v1-...`)

### Введите ключ в приложении:
1. На главном экране найдите блок "OpenRouter API"
2. Вставьте ваш API ключ
3. Выберите модель AI (рекомендуется Claude 3.5 Sonnet)
4. Ключ сохраняется автоматически в localStorage

## ⚠️ Важные замечания

### Безопасность API ключа:
- Ключ хранится в localStorage вашего браузера
- Не передавайте ключ третьим лицам
- Используйте ограничения на spending в OpenRouter

### Ограничения:
- Бесплатный лимит OpenRouter может быть ограничен
- Для больших проектов рекомендуется использовать платный тариф
- Длинные ответы могут обрезаться (max_tokens = 4000)

### Производительность:
- Анализ больших проектов может занять время
- Рекомендуется загружать только необходимые файлы
- Для монолитных проектов лучше анализировать по частям

## 🐛 Решение проблем

### Ошибка "API Error: 401"
- Проверьте правильность API ключа
- Убедитесь что ключ активен на openrouter.ai

### Ошибка "API Error: 429"
- Превышен лимит запросов
- Подождите или увеличьте лимит в настройках OpenRouter

### Медленные ответы
- Попробуйте более быструю модель (Gemini Pro, Mixtral)
- Уменьшите размер анализируемого кода

### Пустой ответ от AI
- Проверьте баланс на OpenRouter
- Попробуйте другую модель
- Упростите запрос
